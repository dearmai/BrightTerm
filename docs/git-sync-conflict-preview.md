# Git 동기화 차이 미리보기

## 사용 방법

1. 설정 → Git 동기화에서 충돌 또는 비밀번호 확인 필요 상태가 나타나면 **차이 미리보기**를 누른다. 로컬 볼트가 열려 있어야 한다.
2. 현재 볼트 키로 원격 내용을 먼저 확인한다. 키가 다르면 **원격 볼트 마스터 비밀번호**를 입력하고 다시 조회한다. 비밀번호는 설정 화면이 열린 동안 메모리에서만 사용하며 잠금·화면 닫기·적용 시 지운다. 메인 프로세스는 입력 비밀번호나 복호화 키를 미리보기 토큰에 보관하지 않는다.
3. 서버·폴더·스니펫·계정·볼트 정보의 건수를 확인하고 종류를 선택한다. 각 항목을 펼치면 **설정 / 이 PC(로컬) / 원격** 표가 나온다.
4. 내용을 확인한 뒤 **원격 데이터 가져오기** 또는 **로컬 데이터 올리기**를 선택한다. 선택은 전체 데이터에 적용되며 기존 확인창을 거친다. 미리보기 전에는 이 버튼들이 비활성화된다.

## 어떤 차이를 보여 주는가

- 항목 ID를 기준으로 **로컬에만 있음 / 원격에만 있음 / 값이 다름**으로 구분한다. 같은 이름이어도 ID가 다르면 별개의 항목이다.
- 서버 주소·포트·사용자·폴더·재접속·마우스 보고·tmux·포워딩 등 변경된 설정과 양쪽 값을 표시한다. 폴더·계정·점프 호스트 참조는 이름과 ID로 표시한다.
- 비밀번호·개인 키·키 암호는 메인 프로세스에서 실제 복호화된 값으로 비교하지만, 응답에는 존재 여부와 다름 여부만 담는다. 렌더러로 평문 비밀값·계정 암호문을 전달하지 않는다.
- 계정의 암호화 표현만 다르고 실제 값은 같으면 이를 구분한다. 볼트의 마스터 비밀번호·복구 코드 잠금 정보 차이도 별도로 표시하며 원문은 숨긴다.
- 스니펫 본문·자동 실행 명령·메모는 **내용 보기**를 눌러 펼친다. 알려진 URL 자격 증명과 민감한 객체 필드는 마스킹하고, 알 수 없는 저장 필드의 원문은 표시하지 않는다.
- 생략된 기본값과 명시된 기본값은 저장 형태의 차이로 표시한다. 예를 들어 마우스 입력 전달 미설정과 true는 기본 동작이 같아도 저장 값은 다르다.
- PC별 최근 사용 시각·폴더 접힘 상태·SSH 신뢰 기록·OS 잠금 해제 정보는 비교 대상이 아니다.

공통 기준 스냅샷을 저장하지 않으므로 어느 쪽에서 추가·삭제했는지 또는 어느 기기가 최신인지는 단정하지 않는다. 수정 시각·암호문이 다르다는 이유만으로 비밀번호가 달라졌다고 표시하지 않는다.

## 조회와 적용

- 조회는 원격을 읽어 로컬 Git 캐시를 갱신할 수 있지만 설정·볼트·동기화 성공 기록을 변경하거나 원격에 푸시하지 않는다. 기존 원격 형식·암호화·16MB 크기 제한·데이터 검증을 사용한다.
- 미리보기 토큰은 5분 동안 유효하며 로컬 지문·원격 지문·저장소 설정에 연결된다. 적용 직전에 다시 fetch하고 지문을 확인한다. 값이 달라지면 덮어쓰지 않고 다시 비교하도록 한다.
- 볼트를 잠그거나 저장소 설정을 바꾸거나 동기화에 성공하면 토큰을 무효화한다. 화면에서도 로컬 목록·계정·설정 변경, 동기화 상태 변화, 만료 시 비교 결과를 지운다.
- 원격 파일이나 브랜치가 없으면 그 사실을 안내하고 원격 가져오기를 비활성화한다. 잘못된 비밀번호·손상 데이터·통신 실패도 비교 결과로 오인하지 않도록 표시한다.
- 원격을 받기 전 로컬 자동 백업과 로컬을 올릴 때 기존 원격을 Git 기록에 보존하는 동작은 유지한다. 원격에 스니펫이 없는 이전 형식 또는 최초 스니펫 합치기 정책도 안내한다.

## 범위와 검증

데스크톱 기능이다. 항목별 병합은 지원하지 않으며 전체 가져오기·전체 올리기 중에서 선택한다. 긴 값은 2400자까지 표시하고 항목은 50개씩 더 볼 수 있다.

- 타입 검사·앱 빌드·비교 단위 테스트 4개 통과.
- 분리된 두 Electron 프로필과 로컬 bare Git 저장소로 조회의 읽기 전용 동작, 키가 다른 볼트, 비밀값 비노출, 실제 화면에서 비교 후 가져오기, 잠금·설정 변경·로컬/원격 변경 후 선택 차단 및 원격 파일 없음 시나리오를 검증했다.
- 기존 Git 동기화 E2E와 말풍선 알림 E2E도 통과했다. 실제 사용자 동기화 저장소의 데이터는 가져오거나 덮어쓰지 않았다.
