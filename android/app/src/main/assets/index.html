SSH 연결

SSH 키 · 시작 명령

한 줄씩 보내고 출력이 멈추면(프롬프트) 다음 줄을 보냅니다. 비밀번호 프롬프트가 나오면 남은 줄은 보내지 않습니다. 빈 줄과 # 주석은 건너뜁니다. 세션 유지(tmux)는 새 세션을 만들 때만 1초 간격으로 실행합니다.

터미널 · 인코딩

접속할 때 서버의 stty erase 도 Backspace 값으로 맞춥니다. 한글이 깨지면 서버 locale(LANG)에 맞추세요 — ko_KR.eucKR·IBM-eucKR 은 EUC-KR.

세션 유지 (tmux)

같은 이름의 세션이 있으면 이어서 연결합니다. 시작 명령은 새 세션을 만들 때만 실행합니다. 마우스 모드에서 텍스트를 선택하려면 Shift+드래그하거나 마우스 모드를 끄세요. 서버에 tmux가 없으면 안내 후 일반 셸로 연결합니다.

기존 서버의 비밀번호·키 암호를 비워 두면 저장된 값을 유지합니다. 자격 증명을 지우려면 서버를 삭제하고 다시 등록하세요.

BrightTerm Android

SSH 비밀번호·개인키 인증, 여러 세션, SFTP 파일 전송, 암호화된 서버 저장을 지원합니다. 백그라운드 연결은 알림에서 종료할 수 있습니다. OS가 프로세스를 종료하면 연결이 끊깁니다. 서버 작업 유지는 tmux를 사용하세요.

Ctrl+Shift+T: 연결 · Ctrl+Tab: 다음 세션
Ctrl+Shift+L: 서버 목록 · Ctrl+Shift+W: 세션 닫기
Ctrl+Shift+C/V: 복사/붙여넣기 · Ctrl +/-: 글자 크기 · Ctrl+,: 설정 · 두 손가락 핀치줌으로 글자 크기 조절
터치 보조키 Ctrl/Alt는 다음 입력 한 번에 적용됩니다.

이 Android 버전은 SSH 중심의 초기 포팅입니다. 데스크톱 백업 파일 가져오기, Telnet, USB 시리얼, 로컬 셸, 점프 호스트·포워딩은 아직 지원하지 않습니다.
