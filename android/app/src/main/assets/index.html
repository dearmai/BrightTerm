BrightTerm Android

SSH 비밀번호·개인키 인증, 여러 세션, SFTP 파일 전송, 암호화된 서버 저장을 지원합니다. 백그라운드 연결은 알림에서 종료할 수 있습니다. OS가 프로세스를 종료하면 연결이 끊깁니다. 서버 작업 유지는 tmux를 사용하세요.

Ctrl+Shift+T: 연결 · Ctrl+Tab: 다음 세션
Ctrl+Shift+L: 서버 목록 · Ctrl+Shift+W: 세션 닫기
Ctrl+Shift+C/V: 복사/붙여넣기 · Ctrl +/-: 글자 크기
터치 보조키 Ctrl/Alt는 다음 입력 한 번에 적용됩니다.

이 Android 버전은 SSH 중심의 초기 포팅입니다. 데스크톱 볼트 가져오기, Telnet, USB 시리얼, 로컬 셸, Git 동기화, 점프 호스트·포워딩은 아직 지원하지 않습니다.
